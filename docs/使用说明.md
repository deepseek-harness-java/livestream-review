# 直播复盘台 · 使用说明

## 1. 这是什么

「直播复盘台」是接入 AI 复盘助手的直播运营工具：

- **经营总览**：场次、累计 GMV/订单、正在直播提醒；
- **场次列表**：点击任意场次加载完整复盘（点击行即可）；
- **复盘详情**：GMV/转化率/客单价/UV 价值/退款率 + 自动结论；
- **商品漏斗**：逐商品曝光→点击→下单，CTR/CVR 进度条 + 断点备注；
- **小时节奏**：在线与 GMV 的小时分布，标注秒杀/福袋/返场事件；
- **主播绩效**：累计 GMV、平均转化、长项与短板；
- **AI 助手（live-copilot）**：复盘找断点、归因峰值、对比主播、给排班与排品建议。

## 2. 启动步骤

前置：本机已运行 DSH 宿主（`127.0.0.1:8090`），JDK 17+、Maven 3.8+。

```bash
mvn clean package -DskipTests
java -Dserver.port=18091 -jar live-app/target/live-app-1.0.0-SNAPSHOT.jar

bash install_plugin.sh \
  live-plugin/target/live-plugin-1.0.0-SNAPSHOT.jar \
  live-copilot 1.0.0-SNAPSHOT \
  live-plugin-1.0.0-SNAPSHOT.jar "直播复盘助手"

open http://127.0.0.1:18091/
```

## 3. AI 助手常用指令

| 你说 | AI 做 |
|------|------|
| “复盘 9.23 美妆场” | 调 `session_review`，给指标 + 结论 |
| “哪个商品拖了后腿” | 调 `goods_funnel` 找 CTR/CVR 断点 |
| “几点是峰值，为什么” | 调 `hour_trend` 归因运营事件 |
| “对比主播表现” | 调 `anchor_perf` 给排班与培养建议 |
| “为什么数码场转化低” | 组合多工具：review + funnel + trend |

## 4. 常见问题

**Q1：AI 无回复？** 确认 DSH 已启动且 `live-copilot` 为 ACTIVE。
**Q2：数据持久化？** 内存演示数据，重启还原；数据层在 `LiveStore`。
